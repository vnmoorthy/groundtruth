# Code of Conduct

This project follows the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## TL;DR

- Be kind. Disagreement is fine; contempt is not.
- Critique ideas, not people.
- Assume good faith. The other person probably has context you don't.
- No harassment, doxxing, or sustained personal attacks.

## Scope

Applies to all project spaces: GitHub Issues, Discussions, Pull Requests, commit messages, and any other forum where people interact under the groundtruth name.

## Enforcement

If something feels off, email the maintainer or use GitHub's "Report content" feature on the offending message. Reports stay confidential.

The maintainer will:

1. Acknowledge the report within 7 days.
2. Investigate using the public record plus any private context the reporter wants to share.
3. Respond with one of: dismiss (no policy violation), warn (private message), temporary block, permanent ban. Decisions are final but appealable in writing.

The maintainer is not impartial in the sense of having no opinion — they have one. The standard is whether a thoughtful person reading the exchange in a year would call it abusive. Edge cases get the benefit of the doubt; clear-cut cases don't.

## Why this is short

Long codes of conduct read like legal disclaimers and rarely change behavior. The Contributor Covenant 2.1 is the canonical long version if you want details. This file is here so you know the rules exist and where the line is.
